Senior Backend Engineer

About the role
We are building a real-time logistics platform and need a senior backend engineer to own core services.

Responsibilities
- Design and build scalable backend services in Python using FastAPI.
- Own PostgreSQL schemas, queries and performance tuning.
- Build event-driven pipelines on a message broker such as Kafka.
- Run services in production, including on-call and incident response.
- Mentor engineers and review code.

Requirements
- 5+ years of backend engineering experience.
- Strong Python and FastAPI skills.
- Deep knowledge of PostgreSQL.
- Production experience with Kubernetes.
- Experience with infrastructure as code, such as Terraform.

Nice to have
- Experience with Kafka or similar streaming systems.
- Familiarity with AWS.
- Open source contributions.
