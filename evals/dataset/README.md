# Golden dataset

Synthetic, fictional resume/JD pairs with hand-labelled expected outputs. Cases are `cases/<id>.json`; resume PDFs are rendered from the text by `uv run python -m scripts.eval_pdfs` (`--check` verifies they are in sync). Labels are ground truth as a recruiter would assign them, not tuned to the offline heuristic; some cases are expected to fail today. `ci` marks the cheap per-PR subset (one per category).
